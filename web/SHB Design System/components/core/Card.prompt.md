The base container surface used for panels, list items, and grouped content.

```jsx
<Card><CustomerSummary /></Card>
<Card padding="var(--space-4)" style={{ maxWidth: 320 }}>Compact card</Card>
```

White surface, subtle 1px border, soft `--shadow-sm`, `--radius-md` corners — the standard SHB elevation for banking UI (low-contrast, not floaty).
